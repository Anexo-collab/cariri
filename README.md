# Explora Brasil - Site de Turismo

Um site simples e responsivo de turismo, feito com HTML e CSS puro.

## Seções

- **Header** — Navegação fixa com logo e menu
- **Hero** — Banner principal com chamada para ação
- **Destinos Populares** — Cards com 6 destinos turísticos brasileiros
- **Sobre** — Informações sobre a agência com estatísticas
- **Galeria** — Grid de fotos com efeitos hover
- **Contato** — Formulário de contato e informações
- **Footer** — Links rápidos e redes sociais

## Como usar

Basta abrir o arquivo `index.html` no navegador.

## Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Poppins)
